# oisinpi (archived)

This repository is archived. Its packages now live in [oisin-ee/dogsled](https://github.com/oisin-ee/dogsled) and
release with it, at the `dogsled` version.

| Old package               | Now                                                                                              |
| ------------------------- | ------------------------------------------------------------------------------------------------ |
| `@oisin-ee/oisinpi`       | Deprecated. Install the packages below directly.                                                 |
| `@oisin-ee/pi-todo`       | Deprecated. The `todo` tool is part of `@oisin-ee/pi-dogsled` since 0.28.1.                      |
| `@oisin-ee/pi-prewalk`    | [`packages/pi-prewalk`](https://github.com/oisin-ee/dogsled/tree/main/packages/pi-prewalk)       |
| `@oisin-ee/pi-tiers`      | [`packages/pi-tiers`](https://github.com/oisin-ee/dogsled/tree/main/packages/pi-tiers)           |
| `@oisin-ee/pi-guardrails` | [`packages/pi-guardrails`](https://github.com/oisin-ee/dogsled/tree/main/packages/pi-guardrails) |

Install in pi:

```sh
pi install npm:@oisin-ee/pi-dogsled
pi install npm:@oisin-ee/pi-prewalk
pi install npm:@oisin-ee/pi-tiers
pi install npm:@oisin-ee/pi-guardrails
```

The history stays here, read-only.
